## Long Description (optional - can be added to repository About section)

```
ElectroShop API is a production-ready e-commerce backend built with ASP.NET Core 8.0, following Clean Architecture and Domain-Driven Design principles. 

Key Features:
• CQRS pattern implementation with MediatR
• Result pattern for consistent error handling
• JWT authentication with refresh tokens
• Pagination support for all list endpoints
• Soft delete pattern
• Global exception handling
• Structured logging with Serilog
• Docker Compose support
• Interactive Swagger/OpenAPI documentation

The project demonstrates best practices in:
• Clean Architecture layering
• Domain-Driven Design
• SOLID principles
• CQRS pattern
• Repository pattern
• Value Objects
• Domain Events

Perfect for learning modern .NET development patterns or as a starting point for your e-commerce API.
```
